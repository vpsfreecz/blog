Thanks to vpsAdminOS, we can now allocate a dedicated /64 IPv6 block to each VPS.

Until recently, we had to allocate only individual addresses (/128) for IPv6 to each virtual server. The original OpenVZ could not handle larger blocks, so there was no other option. Although allocating /64 ranges is only a recommendation, blacklists enforce it in practice, blocking not just spammers but others in the affected ranges.

If you would like your own /64 IPv6 block, just log in to vpsAdmin. Each user can allocate entire address blocks to their VPS themselves. Each contains 18.45×1018 addresses.

When adding it, remember not only to route the new address but also to add it to the VPS interface. You can do this in vpsAdmin with the "Add route and an address to interface venet0" button in the final step. This assigns the /64 block to a specific interface.

How the block is used is up to each user and their applications. We can also set the corresponding reverse records; just contact support.
