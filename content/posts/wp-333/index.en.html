We have new template versions for installing virtual servers. You can try the new Devuan distribution.

At some members' request, we've added Devuan 1.0 beta (website) to our templates. It's a fork of Debian 8 Jessie focused on removing systemd. It uses copies of Debian repositories with only the minimal changes needed to replace the init system. Since it's still a beta, the template isn't shown on the membership application form, but you can install it through vpsAdmin.

We've also tested Fedora 23, which came out a few months ago. It works without problems and is available both on the application form and, of course, in vpsAdmin.

While we were at it, we updated the Gentoo template. The previous one dated from 2014, and updating a system that old to the current version is rather difficult. We'll try to update the Gentoo template more often so it's quicker to put into production.

The final addition is openSUSE 13.2 and Leap 42.1, which we've prepared and tested. Both templates work and are already on the application form. We've removed the unsupported openSUSE 12.3 from it.

One member also asked for a template of the development version of Debian 9 (currently testing). We tried it and it works, but the environment is still too changeable. A systemd update could break it at any time and leave it unable to boot. We therefore won't publish it yet. Anyone who needs testing can change repositories on the current stable release (Jessie) and upgrade. Keeping the system working is then up to them.

See which distributions our members use most often. Debian and Ubuntu lead, followed by CentOS. Together, these three account for over 85%.
