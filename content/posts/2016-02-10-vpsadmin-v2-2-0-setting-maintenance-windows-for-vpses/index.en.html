The new version of our vpsAdmin web interface lets you choose when maintenance can take place on your VPS.

vpsAdmin v2.2.0 lets you set a window for planned outages, migrations and similar work for each VPS. You can choose different times for each day of the week, or exclude a day altogether. The aim is to schedule outages at the most suitable time for each VPS.

We'll mainly use this for migrations between nodes. vpsAdmin can now migrate VPSes in batches while respecting their configured outage windows. Members will also receive emails about the progress of their VPS migration.

By default, VPSes have a daily outage window from 01:00 to 05:00. This doesn't mean a 4-hour outage every day: it means a planned outage may occur during that time. For a migration, for example, this is at most a few minutes. We'll of course announce these outages in advance.

If you can tolerate outages during the day too, please adjust your settings accordingly.

vpsAdmin also stores more information about VPSes, tracking CPU usage, uptime and loadavg. It keeps historical data as well as the current state, accessible through the API. We're collecting this mainly so we can eventually distribute VPSes automatically to give each node an optimal load.

The API version has been raised to 2.0. A new vpsfree-client release mainly contains bug fixes and a new vps migrate_many command for administrators. The full list of changes is in the release notes.
