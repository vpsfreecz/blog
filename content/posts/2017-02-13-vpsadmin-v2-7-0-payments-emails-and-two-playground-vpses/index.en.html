On Friday, I deployed a new version of vpsAdmin, v2.7.0. The main additions include automated membership payment processing, support for multiple email addresses, deleting NAS snapshots from the web UI and optional names for manually created snapshots.

The default number of VPSes among which you can divide your allocated resources has also changed: five in production and two in playground. Playground also provides two IPv4 addresses.

A lot has changed under the hood too. Membership applications and requests to change personal details have moved into the API. Along with plenty of refactoring, all functionality is now available through the API. For example, you can submit a vpsFree application through vpsfreectl.

Payments

Until now, incoming payments were copied manually from the bank account into vpsAdmin. vpsAdmin now has a plugin supporting paying users. Payments are downloaded from the account several times a day through the Fio API. vpsAdmin then sends an email confirming receipt.

All payments with the correct variable symbol (VS, the member's ID) and amount (a multiple of the membership fee) are processed automatically. If someone forgets the VS, we process the payment manually. If we cannot match it by name either, you will need to contact support. Nothing changes in that respect; it will work as before.

Additional payments for extra VPSes and similar things will use a different VS. Arrange that with Michal at support.

Multiple contact email addresses

Some members wanted to register more than one email address in vpsAdmin, particularly companies where several people manage the membership and VPSes.

vpsAdmin defines two contact types (roles): VPS administrator and account (membership) administrator. Messages sent by vpsAdmin are divided between these roles, and you can choose who receives them.

For example, the account (membership) administrator receives membership payment reminders and notices about membership suspension or renewal. The VPS administrator receives emails about VPS state changes, configuration changes, backup downloads and VPS migrations.

You can set multiple email addresses for each role. If that division is not enough, there are more detailed settings where you can choose whether to receive each type of message and at which addresses.

More information in the knowledge base.

If the existing single-address setting suits you, there is no need to change anything.

Snapshots

The web UI finally lets you delete NAS snapshots. Previously, you could create them there but had to use the API directly to delete them.

When creating a VPS or NAS snapshot, you can give it any name to help identify it later.

Plugin system

To keep the vpsAdmin core as simple as possible, I decided to add functionality outside its main purpose as plugins. The vpsAdmin core should manage VPSes, storage and networking.
Other things, such as payments and user requests, are therefore implemented as plugins.

Other changes

This release finally completes the move of functionality from the original web interface into the API. The web UI has been completely disconnected from the database. Everything you see is loaded from the API.

The full list of changes is in the release notes.
