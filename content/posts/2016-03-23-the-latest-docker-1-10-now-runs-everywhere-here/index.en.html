The latest kernel update lets us run Docker 1.10 on all our VPSes.

Docker is popular, widely discussed and increasingly used. Our members want it too, and we try to support it. Unfortunately, we depend on the OpenVZ kernel developers to backport features from newer kernels into their version. As Docker develops, the list of features it requires grows.

Until recently, our VPSes could only run Docker up to version 1.7, while the current release is 1.10. We had to wait for the new features to appear in OpenVZ and gradually updated the kernels on individual nodes. The latest version is now everywhere, as you can see on the vpsAdmin front page.

On all VPSes (including playground), Docker now runs up to version 1.10 and automatically detects that it should use the VFS storage driver. So we are Docker-friendly.
