The new HaveAPI release mainly adds support for long-running blocking actions.

HaveAPI version 0.7 lets clients monitor the progress of blocking actions or block until they finish, as the console client does, for example. In our API, these include creating a VPS, reinstalling, starting/stopping/restarting, cloning, swapping and so on.

The online documentation has also improved. It now shows usage examples in each client's syntax (Ruby/JS/PHP/FS/curl/HTTP).

The documentation links directly to haveapi-webui, which connects to the API so you can start using it straight away.

The full list of changes is in the individual repositories' changelogs. Our API will run this version tomorrow.
