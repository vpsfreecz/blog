The OpenVZ technology we use is reaching the end of its life, and development has stopped. We're therefore moving to a newer solution, vpsAdminOS.

We currently use OpenVZ Legacy container virtualization to run VPSes on all nodes. As it's ageing, development has ended and new distributions are dropping support, we're working on a move to vpsAdminOS (GitHub). This distribution is based on NixOS and not-os, and will serve as the hypervisor for VPSes on our nodes.

We've written our own tool, osctl, for managing VPSes (containers), with features comparable to OpenVZ's vzctl or LXD. It mainly handles user namespaces for proper VPS isolation and cgroups for memory, CPU and other limits. LXC starts the containers.

vpsAdminOS isn't limited to vpsFree.cz infrastructure. If you run OpenVZ Legacy elsewhere and aren't sure what to do next, consider vpsAdminOS, which is ready for migrating OpenVZ containers.

We've been working on vpsAdminOS since roughly autumn 2017, and all members can now try running VPSes on the new system. Our goal is for migrations from OpenVZ to vpsAdminOS to go unnoticed, though that depends on what you run in your VPS. We recommend that everyone try a new VPS and report any problems or shortcomings. We need to fine-tune the OS and its vpsAdmin integration before migrating production VPSes.

Essentially, you get another playground VPS, with similar conditions. It may be a bit wilder, though: unannounced outages, restarts when we need to update something, and so on. In vpsAdmin's VPS creation form, select the Staging location. Alpine, Arch, CentOS, Debian, Fedora, Gentoo, NixOS and Ubuntu are available so far; more will follow.

You have several weeks to months to test and report bugs, depending on how things go. More information about OS and vpsAdmin changes and the transition plan is in the knowledge base.
