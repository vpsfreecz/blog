At vpsFree.cz, we've written our own set of scripts to make building customized operating system templates easier.

You can find all the scripts and templates on GitHub. They make it fairly easy to add settings specific to vpsFree.cz to our templates, such as automatically enabling the remote console available in vpsAdmin, or installing commonly used packages such as "vim", and so on...

We keep all available templates on central NFS storage, so they're identical across all servers. You can then install a template on your VPS with one click in vpsAdmin.

In the near future, we plan to generate templates automatically, backing up the previous template and replacing it with the new one. Why back up templates? Something might change in a distribution, and the script might build the template successfully, yet the installed system could have various errors or problems. We want to be able to take a step back until the bug is fixed.

If you'd like to use a Linux distribution we don't offer, we'd welcome a template for it, such as the one for CentOS 7, which we've just deployed. First, specify the distribution and version you want, and list any packages to install automatically in EXTRAPKGS. For system-specific configuration, you can use:

configure-append <<EOF
... zde uvedeme potřebné příkazy ...
EOF
