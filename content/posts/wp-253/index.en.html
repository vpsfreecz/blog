We have deployed version 2.1 of the vpsAdmin interface, which adds, among other things, remote access to the VPS console.

vpsAdmin 2.1.0 uses HaveAPI v0.4, so its main change is a reworked CLI. This also lets you connect to the remote VPS console:

$ vpsfreectl vps remote_console <vps id>

This console works much better than the one in a web browser. Your terminal simply renders it, without having to do anything complicated in JavaScript. It also adapts to the terminal window size. The implementation is described in the vpsAdmin documentation.

The new CLI features are described in the email about HaveAPI v0.4 and the knowledge-base article.

Another change concerns setting a VPS hostname. This was always managed through vpsAdmin, which set it and overwrote /etc/hosts every time the VPS started. You can now manage the hostname manually, outside vpsAdmin.

The full list of changes is in the release notes. The knowledge-base console guide has a few tips on configuring it correctly.
