We want to welcome members who do not speak Czech or Slovak too. We have started with vpsAdmin, which now knows English.

vpsAdmin v2.4.0 adds support for the English translation of the vpsFree.cz website, which should launch soon. The change only concerns the language in which vpsAdmin sends emails, mainly information for new members after their applications are approved and, after that, most often
payment reminders.

You can change the language in your profile settings: vpsAdmin → Edit profile → Language dropdown. The default is Czech. Change it if you like. The language setting applies only to emails sent by vpsAdmin and has no other effect yet.

All our templates are stored on GitHub and installed in the API by a new vpsAdmin component, the vpsadmin-mail-templates script.
