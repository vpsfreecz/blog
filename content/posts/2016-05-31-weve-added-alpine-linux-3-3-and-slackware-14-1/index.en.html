We've added two more distribution templates.

You can select Alpine Linux 3.3 or Slackware 14.1 directly on the membership application form.

Alpine Linux is a minimal distribution focused on security. It's based on musl libc and BusyBox, with OpenRC as its init system. Unfortunately, we can't use the PaX and grsecurity kernel patches it otherwise includes.

At 5.5 MB, Alpine is the smallest template we've ever had. By comparison, Debian 8 is 121 MB and CentOS 7 needs 244 MB. Jakub Jirůtka created this template; thank you!

Slackware is the oldest distribution still active. It values simplicity and stability: its package manager, for example, is implemented in bash and doesn't handle dependencies. A package is an ordinary tar.{gz,xz} archive, installed by extracting it into /.

The only complication was networking: the built-in init scripts can't configure more than one IPv4 address on an interface, and don't support IPv6 at all. We solved this with our own init script and a vzctl patch. It's described further in the template.
