Testing our vpsAdminOS platform is entering another significant phase: you can clone production VPSes from OpenVZ to staging with vpsAdminOS.

Clone a VPS just as you would to Playground, but select the Staging location, which runs vpsAdminOS. Pay attention to the "Stop" checkbox: you can choose whether to shut down the production VPS while cloning to create a consistent snapshot, flushing data from memory to disk. For a simple staging test, this may not be necessary, so you can clone without restarting the production VPS. Everything is cloned except mounts, which are removed for now.

If you want to clone a larger VPS, or already have something on staging, please contact support and we'll increase your staging RAM/HDD allowance so it fits.

I now expect more interest in testing whether everything you need works. We want the eventual VPS migrations to be reliable and require little attention from VPS administrators, so please report anything you encounter so we can prepare. Please write even if everything works. We need to know where we stand, what works and what doesn't.

After cloning, these should work:

  • IPv4/IPv6 networking
  • the remote console
  • ideally, all services in the VPS

If any of these don't work, or need configuration changes because of the different virtualization or kernel, please tell us.

We'd like to start migrating all production VPSes in Q1/Q2 2019, depending on what remains to be finished. The OpenVZ team will end support for the OpenVZ Legacy kernel in November 2019, so we want to move as many VPSes as possible to vpsAdminOS by then.
