To protect our members, we are introducing two-factor authentication in vpsAdmin using TOTP.

You can now set up two-factor authentication (2FA) using TOTP in vpsAdmin. For example, you can authenticate with a phone running Google Authenticator, FreeOTP or any program implementing TOTP. To set it up, scan the QR code with the application or enter the secret key. The application can then display the current login password at any time; it changes every 30 seconds.

You can add several authentication devices to vpsAdmin and use whichever you have to hand to log in. Two-factor authentication is enforced if at least one device is configured and enabled. Without that device, you cannot log in to vpsAdmin, either through the web interface or the API.

If you lose your authentication device, you can use the recovery code vpsAdmin shows you once when setting up the device.

The setup procedure, with screenshots, is described in the knowledge base.

Introducing 2FA required a backwards-incompatible change to the HaveAPI protocol. If you use vpsfreectl or another library for accessing the API, you must update it.
