HaveAPI version 0.6 is out, bringing a web interface.

The main addition in HaveAPI version 0.6 is haveapi-webui, a client for administering any API based on HaveAPI. I'd compare it to phpMyAdmin, which can administer any MySQL database.

haveapi-webui only needs the API server's URL. It's a full client: you can browse all objects, authenticate, call any action, enter input parameters and see the output.

You can try it with our API (your vpsAdmin credentials work;
it's an alternative UI for vpsAdmin):

https://projects.vpsfree.cz/haveapi-webui/master/vpsfree/

For example, the cluster's public status:

https://projects.vpsfree.cz/haveapi-webui/master/vpsfree/2.0/node/public_status/?_exec=1

Or, more generally, with any other API:

https://projects.vpsfree.cz/haveapi-webui/master/general/

It's all written in JavaScript, so naturally it doesn't work without it. I haven't optimized it yet; expect to download about 1.5 MB of JS baggage.

In the future, I'd like to use components from this application to build a new vpsAdmin web interface, unless someone else wants to take it on.
