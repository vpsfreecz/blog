We've updated the Arch Linux template and added Void Linux for you to use.

After more than a year, we've updated the Arch Linux template. It comes with systemd version 230, with updates disabled in pacman's configuration as a precaution. On several occasions, a new version hasn't worked under OpenVZ. It then takes time for the OpenVZ developers to catch up, and for us to deploy the new kernel afterwards.

We've also added a template for Void Linux. Like Arch, it's a rolling release. Void has its own XBPS package manager, uses runit as its init system, and LibreSSL instead of OpenSSL. You can
choose a version with either glibc or musl libc.
