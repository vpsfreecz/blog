We've launched our own service for sharing code snippets, program output and text in general.

The new service is at paste.vpsfree.cz. Without logging in, you can only post text with a limited expiry time. Members can log in with their vpsAdmin credentials and keep text for longer.

The service uses HaveSnippet, which I wrote a few years ago as a school project and have now polished up. It also has a command-line client, so you can post text like this:

$ cat soubor.txt | havesnippet
$ havesnippet soubor.txt

The program also has a version with the shorter name hs:

# cat soubor.txt | hs

First, configure the client:

  1. gem install havesnippet-client
  2. Log in to paste.vpsfree.cz in a web browser, open settings and create an API key
  3. havesnippet -s https://paste.vpsfree.cz -k <vytvořený api klíč> --save
  4. echo hotovo | havesnippet

Further program options are described in the README.
