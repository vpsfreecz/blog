We've released a new version of our vpsAdmin interface. The main addition is downloading backups from the CLI.

vpsAdmin v2.3.0 makes it easy to download VPS/NAS backups from the CLI. Previously, you had to wait for an email with a download link. Now there's no waiting: the download starts immediately. You can also choose between a conventional tar.gz archive and a ZFS data stream, which we can send incrementally, transferring only changes since the previous snapshot.

vpsfree-client has four new commands for manual and automated backup downloads.

Download a backup to a file:

# vpsfreectl snapshot download [<id>] -- --format archive/stream

You don't need to worry about interrupting a download. The next time you run the program, it asks whether to resume it.

Download a data stream (like zfs send):

# vpsfreectl snapshot send <id> | zfs recv <dataset>

Request an incremental stream with -I, --from-snapshot:

# vpsfreectl snapshot send <id2> -- --from-snapshot <id1> | zfs recv

Finally, the client can handle all the backup download logic for you with the command

# vpsfreectl backup vps [<id>] <cílový dataset>

or

# vpsfreectl backup dataset [<id>] <cílový dataset>

The program works out which snapshots to download and whether it can do so incrementally or needs a full backup. Downloads go straight into a ZFS dataset, so you must have ZFS installed and a zpool imported. Snapshots are also rotated: old ones are deleted to make room for new ones. Just put this command in crontab, and backup
downloads are taken care of.

All these commands have a --max-rate option to limit download speed. A checksum is also available for the downloaded file, and the program always verifies it.

Before using this, I recommend reading the KB, which describes the commands and their options in more detail, with examples.
