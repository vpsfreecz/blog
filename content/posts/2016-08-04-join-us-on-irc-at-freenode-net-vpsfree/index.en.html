For a while now, we've been using #vpsfree on freenode.net alongside our Jabber MUC. It's much more active than Jabber, where nothing happens any more.

Today, we reached the point where everything important is ready on IRC, so it can fully replace the Jabber MUC.

How do you connect?

  • Server: chat.freenode.net
  • Channel: #vpsfree
  • Web client: webchat.freenode.net
  • Native clients: Pidgin, Irssi, Adium, etc.
  • Archive

We've set up an IRC bouncer (ZNC) for members. If you'd like to use it, ask on IRC or contact support.

Our own bot on the channel creates the web archive linked above, responds to commands and watches events such as outage-list messages and vpsAdmin updates, which it announces on the channel.
For more information, see the KB.
