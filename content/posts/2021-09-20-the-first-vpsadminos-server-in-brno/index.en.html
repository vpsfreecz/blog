Today, we brought node5.brq online, the first vpsAdminOS node in Brno.

If you'd like to move from OpenVZ, contact support. On vpsAdminOS, we also allocate /64 IPv6 addresses. You can replace your OpenVZ /128 addresses yourself through vpsAdmin; see the earlier blog post.

For now, NAS access is more complicated. From vpsAdminOS in Brno, you can only access the NAS with a private address first on the network interface. But that means internet traffic goes through NAT: the public address isn't used as the source because it isn't first.

This is because NAS exports on vpsAdminOS are mounted inside the VPS. On OpenVZ, vpsAdmin mounted them from the host, so the VPS's internal network didn't matter.

We've since adjusted the network configuration so a private address is no longer needed. The requirement to mount NFS inside the VPS on vpsAdminOS remains unchanged.

Eventually, we'd like to solve this with a second network interface for private addresses and the NAS. But that would take more time, and we didn't want to postpone vpsAdminOS deployment in Brno any longer.
